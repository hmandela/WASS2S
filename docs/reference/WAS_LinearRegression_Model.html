WAS_LinearRegression_Model

WAS_LinearRegression_Model(nb_cores=1, dist_method='nonparam')

Simple Linear Regression model for spatiotemporal climate prediction.

This class implements ordinary least squares linear regression (via scikit-learn’s LinearRegression) to model linear relationships between predictors and a continuous predictand (e.g., seasonal rainfall totals, temperature anomalies, agro-climatic indices).

Key features: - Basic linear modeling (no polynomial features or regularization by default) - Spatially parallel fitting and prediction across large grids using dask + xarray - Deterministic point predictions with optional error computation - Probabilistic tercile forecasting (Below/Normal/Above = PB/PN/PA) using either: - Parametric best-fit distributions per grid cell (‘bestfit’) - Non-parametric sampling of historical forecast errors (‘nonparam’)

Ideal as a baseline model or when relationships are expected to be approximately linear.

Parameters

Name Type Description Default
nb_cores int Number of CPU cores for parallel processing (dask workers). 1
dist_method (bestfit, nonparam) Method for computing tercile probabilities: - ‘bestfit’ → uses best-fit distribution per grid cell (requires distribution fit inputs) - ‘nonparam’ → empirical sampling of historical forecast errors 'bestfit'

Attributes

Name Type Description
nb_cores, dist_method Stored initialization parameters.

Functions

  • fit_predict: Fits linear regression on one grid cell and returns [error, prediction] or just prediction.
  • compute_model: Parallel linear regression across the entire spatial domain. Returns xarray.DataArray with dims (‘output’=[‘error’,‘prediction’], Y, X).
  • compute_prob: best_code_da=None, best_shape_da=None, best_loc_da=None, best_scale_da=None) Computes tercile probabilities for deterministic hindcasts.
  • forecast: Predictor_for_year, best_code_da=None, best_shape_da=None, best_loc_da=None, best_scale_da=None) Full end-to-end forecast pipeline for one target year:
  • deterministic linear prediction
  • tercile probabilities (PB, PN, PA)

Notes

  • Input data requirements:
    • Target (y) should be continuous (rainfall, temperature, etc.).
    • Predictors (X) should be continuous or properly encoded.
  • Negative predictions are automatically clipped to zero (useful for rainfall or non-negative variables).
  • Linear regression assumes linear relationships; for non-linear patterns, consider higher-degree polynomial, tree-based models (XGBoost, RF), or neural approaches (MLP).
  • Large spatial domains benefit significantly from higher nb_cores.
  • For dist_method='bestfit', distribution fit results from WAS_TransformData must be provided.
  • No explicit feature or target scaling is applied (linear regression coefficients adjust automatically, but centering/scaling predictors can improve numerical stability when features have very different scales).

Warnings

  • Linear regression can produce unrealistic negative predictions for non-negative variables (e.g., rainfall); clipping is applied automatically but may bias results.
  • Assumes homoscedasticity and no strong multicollinearity; check residuals and VIF if needed.
  • Small per-grid-cell training sets can lead to unstable coefficient estimates.
  • For very non-linear relationships, performance will be poor compared to tree-based or spline models.

calculate_tercile_probabilities_bestfit

WAS_LinearRegression_Model.calculate_tercile_probabilities_bestfit(
    best_guess,
    error_variance,
    T1,
    T2,
    dist_code,
    dof,
)

Generic tercile probabilities using best-fit family per grid cell.

Inputs (per grid cell): - best_guess : 1D array over T (hindcast_det or forecast_det) - T1, T2 : scalar terciles from climatological best-fit distribution - dist_code : int, as in _ppf_terciles_from_code - shape, loc, scale : scalars from climatology fit

Strategy: - For each time step, build a predictive distribution of the same family: * Use best_guess[t] to adjust mean / location; * Keep shape parameters from climatology. - Then compute probabilities: * P(B) = F(T1) * P(N) = F(T2) - F(T1) * P(A) = 1 - F(T2)

Parameters

Name Type Description Default
best_guess array - like Forecast/hindcast best estimates. required
error_variance float Variance of prediction errors. required
T1 float Lower tercile threshold. required
T2 float Upper tercile threshold. required
dist_code int Distribution code (1-8). required
shape float Shape parameter. required
loc float Location parameter. required
scale float Scale parameter. required

Returns

Name Type Description
array - like Probabilities [P(B), P(N), P(A)].

Notes

  • Uses :math:F as the CDF of the predictive distribution.

compute_prob

Compute tercile probabilities for deterministic hindcasts.

If dist_method == ‘bestfit’: - Use cluster-based best-fit distributions to: * derive terciles analytically from (best_code_da, best_shape_da, best_loc_da, best_scale_da), * compute predictive probabilities using the same family.

Otherwise: - Use empirical terciles from Predictant climatology and the selected parametric / nonparametric method.

Parameters

Name Type Description Default
Predictant xarray.DataArray Observed data (T, Y, X) or (T, Y, X, M). required
clim_year_start int or str Climatology period (inclusive) for thresholds. required
clim_year_end int or str Climatology period (inclusive) for thresholds. required
hindcast_det xarray.DataArray Deterministic hindcast (T, Y, X). required
best_code_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None
best_shape_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None
best_loc_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None
best_scale_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None

Returns

Name Type Description
hindcast_prob xarray.DataArray Probabilities with dims (probability=[‘PB’,‘PN’,‘PA’], T, Y, X).

weibull_shape_solver

WAS_LinearRegression_Model.weibull_shape_solver(k, M, V)

Function to find the root of the Weibull shape parameter ‘k’. We find ‘k’ such that the theoretical variance/mean^2 ratio matches the observed V/M^2 ratio.

 

Developed to support the WMO guidelines for objective, operational seasonal forecasting.
