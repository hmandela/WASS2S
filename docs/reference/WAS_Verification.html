WAS_Verification

WAS_Verification(dist_method='nonparam', mae_rmse_crps_thrsd=100)

Verification class for evaluating weather and climate forecasts.

Provides methods to compute deterministic, probabilistic, and ensemble-based metrics, as well as visualization tools for model performance assessment.

calculate_groc

WAS_Verification.calculate_groc(

    y_probs,

    n_classes=3,
)

Compute Generalized Discrimination (GROC) score according to Weigel and Mason (2011).

The GROC score averages the Area Under the ROC Curve (AUC) for each category, measuring the ability to distinguish occurrences from non-occurrences of each category.

Parameters

Name Type Description Default
y_true array - like Observed values. required
y_probs array - like Forecast probabilities with shape (n_classes, n_samples). required
index_start int Start index of the climatology period for computing terciles. required
index_end int End index of the climatology period for computing terciles. required
n_classes int Number of classes (default is 3 for terciles). 3

Returns

Name Type Description
float GROC score, ranging from 0 to 1. Returns np.nan if insufficient valid data.

Reference

Weigel, A. P. and Mason, S. J. (2011). The generalized discrimination score for ensemble forecasts. Monthly Weather Review, 139(9):3069-3074.

calculate_tercile_probabilities_bestfit

WAS_Verification.calculate_tercile_probabilities_bestfit(
    best_guess,
    error_variance,
    T1,
    T2,
    dist_code,
    dof,
)

Generic tercile probabilities using best-fit family per grid cell.

Inputs (per grid cell): - best_guess : 1D array over T (hindcast_det or forecast_det) - T1, T2 : scalar terciles from climatological best-fit distribution - dist_code : int, as in _ppf_terciles_from_code - shape, loc, scale : scalars from climatology fit

Strategy: - For each time step, build a predictive distribution of the same family: * Use best_guess[t] to adjust mean / location; * Keep shape parameters from climatology. - Then compute probabilities: P(B) = F(T1), P(N) = F(T2) - F(T1), P(A) = 1 - F(T2).

gcm_compute_prob

WAS_Verification.gcm_compute_prob(
    Predictant,
    clim_year_start,
    clim_year_end,
    hindcast_det,
    best_code_da=None,
    best_shape_da=None,
    best_loc_da=None,
    best_scale_da=None,
)

Compute tercile probabilities for deterministic hindcasts.

If dist_method == ‘bestfit’: - Use cluster-based best-fit distributions to: * derive terciles analytically from (best_code_da, best_shape_da, best_loc_da, best_scale_da), * compute predictive probabilities using the same family.

Otherwise: - Use empirical terciles from Predictant climatology and the selected parametric / nonparametric method.

Parameters

Name Type Description Default
Predictant xarray.DataArray Observed data (T, Y, X) or (T, Y, X, M). required
clim_year_start int or str Climatology period (inclusive) for thresholds. required
clim_year_end int or str Climatology period (inclusive) for thresholds. required
hindcast_det xarray.DataArray Deterministic hindcast (T, Y, X). required
best_code_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None
best_shape_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None
best_loc_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None
best_scale_da xarray.DataArray Output from WAS_TransformData.fit_best_distribution_grid, required for ‘bestfit’. None

Returns

Name Type Description
hindcast_prob xarray.DataArray Probabilities with dims (probability=[‘PB’,‘PN’,‘PA’], T, Y, X).

weighted_gcm_forecasts

WAS_Verification.weighted_gcm_forecasts(
    Obs,
    best_models,
    scores,
    lead_time,
    model_dir,
    clim_year_start,
    clim_year_end,
    variable='PRCP',
)

Generate weighted ensemble forecasts from selected GCMs based on their performance scores.

Combines hindcasts and forecasts from multiple models using weights derived from the GROC score, scales the results to match observed climatology, and computes tercile probabilities.

Parameters

Name Type Description Default
Obs xarray.DataArray Observed data with dimensions (T, Y, X), used for scaling and probability calculations. required
best_models dict Dictionary of model identifiers (keys) to be included in the ensemble. required
scores dict Dictionary containing scores (e.g., GROC) for each model, with model identifiers as keys. required
lead_time list of int Lead times in months for the forecast season (e.g., [1, 2, 3] for a 3-month season). required
model_dir str or Path Directory containing hindcast and forecast NetCDF files. required
clim_year_start int or str Start year of the climatology period for computing tercile thresholds. required
clim_year_end int or str End year of the climatology period for computing tercile thresholds. required
variable str Variable name in the NetCDF files (e.g., ‘PRCP’ for precipitation). Default is ‘PRCP’. 'PRCP'

Returns

Name Type Description
tuple - hindcast_det : xarray.DataArray Weighted deterministic hindcast with dimensions (T, Y, X). - hindcast_prob : xarray.DataArray Tercile probabilities for hindcasts with dimensions (probability, T, Y, X). - forecast_prob : xarray.DataArray Tercile probabilities for forecasts with dimensions (probability, Y, X).

Notes

  • Model files are expected to follow a naming convention like ‘hindcast_{center}{variable}{init_month}{season}{lead}.nc’.
  • The GROC score is used as the weighting metric.
  • A scaling factor is applied based on the ratio of observed to hindcast mean.
 

Developed to support the WMO guidelines for objective, operational seasonal forecasting.
